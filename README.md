# 🚀 Rocket Manager — Backend
 
API REST do sistema de gestão de projetos Rocket Manager, desenvolvida com Spring Boot.
 
## 🛠️ Tecnologias
 
- Java com Spring Boot
- Spring Security + JWT
- Spring Data JPA + Hibernate
- PostgreSQL (Supabase)
